# Documentation Note

The documents in this folder support the planning, design, research and implementation of the **UK Energy Reliability Tool** capstone project.

## Use of Generative AI

Generative AI was used as a supporting tool during the documentation process, primarily to:

- expand rough notes and short-form ideas into clearer written explanations;
- improve structure, formatting and consistency across documents;
- help organise implementation plans, feature breakdowns and project timelines;
- rephrase or condense material for different versions of the proposal;
- assist with Markdown conversion and document presentation.

## Originality

The underlying project idea, direction, feature concepts, research questions, design decisions and implementation choices are my own.

This includes the core concept of building a UK energy reliability tool, the decision to focus on supply-demand margin forecasting, the intended user groups, the project scope, the prioritisation of data sources, and the decisions made throughout the project as its feasibility was tested and refined.

Generative AI was used to help develop and communicate these ideas, but it was not the source of the project concept itself.

## Research and Verification

Where external facts, APIs, datasets, products or technical references are discussed, the relevant sources are cited within the associated documents.

API behaviour and project assumptions are also intended to be verified during implementation rather than relying solely on AI-generated descriptions or third-party summaries.

## Purpose of These Documents

These files are working project documentation rather than a record of fully AI-generated deliverables. They show the progression from initial concept through research, scoping, proposal development and implementation planning.
